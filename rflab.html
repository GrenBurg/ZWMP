Model: Eₛ/N₀ = EIRP − FSPL − atmosphere/rain + G/T + 228.6 − 10·log(Rₛ), with Rₛ = data rate / spectral efficiency of the mode (bits per symbol × code rate, incl. Reed-Solomon overhead) and occupied bandwidth Rₛ·(1+α), α = 0.20. G/T assumes 65 % dish efficiency and 150 K; path 35 786 km (GEO). Modem modes, data-rate ranges and Eb/N₀ values come from the Comtech EF Data datasheets (DMD2050E, rev. 10/2016; SLM-5650A, rev. 3/2014): required Eb/N₀ is the guaranteed value at BER 10⁻⁶ (typical in brackets), and BER after FEC is interpolated between the datasheet points. Generic mode uses indicative values. Data rates are n × 64 kbit/s. Rain attenuation is a rough temperate-climate estimate. The waveform is scaled: a real symbol spans thousands of carrier cycles.
